1. Install Node.js (nodejs.org)
2. In this folder run:  npm install
3. Start:               npm start
   Website: http://localhost:3000     Admin: http://localhost:3000/admin.html
4. Default admin password: manjit@123  -> change it:
   Windows: set ADMIN_PASSWORD=yourpass && npm start
   Mac/Linux: ADMIN_PASSWORD=yourpass npm start
Data (images list, reviews, inquiries) is saved in data.json; uploads go in public/uploads.
